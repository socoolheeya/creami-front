# 객실 관리 기능 설계

## 개요

객실(Room) 관리 기능을 4단계 위저드 방식으로 구현합니다.
각 객실은 반드시 하나의 숙소에 속하며, 객실 목록은 테이블 뷰와 카드 뷰를 토글하여 선택할 수 있습니다.

## 페이지 구조

### 라우팅
- `/rooms` - 객실 목록 (전체 숙소의 객실, 테이블/카드 뷰 토글)
- `/rooms/new` - 신규 객실 등록 (위저드, 숙소 선택 필요)
- `/rooms/new?accommodation=[id]` - 특정 숙소의 객실 등록 (숙소 미리 선택됨)
- `/rooms/[id]` - 객실 상세 보기
- `/rooms/[id]/edit` - 객실 수정 (위저드)

### 진입점
1. **독립 경로**: 사이드바 "객실 관리" → `/rooms`
2. **숙소에서**: `/properties/[id]` 상세 페이지 내 "객실 추가" 버튼 → `/rooms/new?accommodation=[id]`

## 데이터 구조

### Room 타입
```typescript
export type RoomType = 'single' | 'double' | 'twin' | 'suite' | 'deluxe' | 'family'

export type RoomStatus = 'available' | 'unavailable' | 'maintenance'

export type BedType = 'single' | 'double' | 'queen' | 'king' | 'sofa'

export type ViewType = 'ocean' | 'city' | 'garden' | 'mountain' | 'pool' | 'none'

export interface BedConfig {
  type: BedType
  count: number
}

export interface RoomImage {
  id: string
  url: string
  isPrimary: boolean
  order: number
}

export interface Room {
  id: string

  // Step 1: Basic Info
  name: string                    // 예: "101호", "디럭스 더블"
  type: RoomType
  accommodationId: string         // 소속 숙소 ID
  accommodationName?: string      // 표시용 (조인 데이터)

  // Step 2: Room Details
  size: number                    // 평수 또는 sqm
  sizeUnit: 'sqm' | 'pyeong'     // 단위
  floor: number                   // 층수
  bedConfiguration: BedConfig[]   // 침대 구성
  standardOccupancy: number       // 기준 인원
  maxOccupancy: number           // 최대 인원
  extraBedAvailable: boolean      // 엑스트라 베드 가능 여부
  extraBedCount?: number         // 가능한 엑스트라 베드 수

  // Step 3: Features & Amenities
  viewType: ViewType
  smokingAllowed: boolean
  amenities: string[]            // 객실별 편의시설
  accessibilityFeatures: string[] // 장애인 편의시설

  // Step 4: Images
  images: RoomImage[]

  status: RoomStatus
  createdAt: Date
  updatedAt: Date
}
```

### 카드 뷰 컴포넌트
- **썸네일**: 대표 이미지 (16:9 비율, 높이 200px)
- **상태 뱃지**: 우측 상단 (이용가능/불가/점검중)
- **객실명**: Bold, 18px
- **숙소명**: 회색, 14px
- **주요 정보**: 타입, 크기, 수용인원 아이콘 표시
- **액션 버튼**: 수정, 더보기 메뉴

### 테이블 뷰 컴포넌트
- **컬럼**: 객실명, 숙소명, 타입, 크기, 수용인원, 상태, 액션
- **정렬**: 각 컬럼 클릭으로 오름차순/내림차순
- **행 클릭**: 상세 페이지로 이동
- **체크박스**: 일괄 작업용 (향후 확장)

### 상단 기능
- **검색**: 객실명으로 실시간 검색
- **숙소 필터**: 드롭다운으로 특정 숙소 선택
- **정렬**: 최신순, 이름순, 크기순
- **뷰 토글**: 카드/테이블 뷰 전환 버튼
- **신규 등록 버튼**: Primary 컬러, 우측 상단 고정

## Wizard UI (4단계 등록/수정)

### 전체 레이아웃
```
┌─────────────────────────────────────────┐
│ [1 기본정보] → [2 객실정보] → [3 특징] → [4 이미지] │
│    ●            ○            ○          ○      │
├─────────────────────────────────────────┤
│                                         │
│         현재 단계 폼 내용                 │
│                                         │
│                                         │
├─────────────────────────────────────────┤
│ [< 이전]                      [다음 >]  │
│                        (마지막: [완료]) │
└─────────────────────────────────────────┘
```

### Step 1: 기본정보
**필드:**
- 객실명 (필수, 텍스트) - 예: "101호", "디럭스 오션뷰"
- 객실 타입 (필수, 드롭다운: 싱글/더블/트윈/스위트/디럭스/패밀리)
- 소속 숙소 (필수, 드롭다운 또는 자동 설정)
  - URL에 `?accommodation=[id]` 있으면 자동 선택 & 비활성화
  - 없으면 드롭다운으로 선택

**유효성 검사:**
- 모든 필수 필드 입력 확인
- 객실명 중복 체크 (같은 숙소 내)

### Step 2: 객실 정보
**필드:**
- 객실 크기 (필수, 숫자)
- 크기 단위 (필수, 라디오: ㎡/평)
- 층수 (필수, 숫자)
- 침대 구성 (필수, 동적 추가)
  - 침대 타입 선택 (싱글/더블/퀸/킹/소파)
  - 개수 입력
  - [+ 침대 추가] 버튼
- 기준 인원 (필수, 숫자)
- 최대 인원 (필수, 숫자, 기준 인원 이상)
- 엑스트라 베드 가능 (체크박스)
- 엑스트라 베드 개수 (조건부, 체크 시 활성화)

**유효성 검사:**
- 크기 > 0
- 최대 인원 >= 기준 인원
- 침대 구성 최소 1개 이상

### Step 3: 특징 및 편의시설
**필드:**
- 뷰 타입 (필수, 드롭다운: 오션뷰/시티뷰/가든뷰/마운틴뷰/풀뷰/뷰없음)
- 흡연 가능 (라디오: 금연/흡연 가능)
- 객실 편의시설 (선택, 체크박스 그리드)
  - TV, 에어컨, 냉장고, 미니바, 커피머신 등
- 장애인 편의시설 (선택, 체크박스 그리드)
  - 휠체어 접근 가능, 넓은 출입구, 욕실 손잡이 등

### Step 4: 이미지
**기능:**
- 드래그앤드롭 업로드 영역 (숙소와 동일)
- 클릭하여 파일 선택 (multiple)
- 업로드된 이미지 관리
  - 썸네일 그리드 (4열)
  - 드래그로 순서 변경
  - 별 아이콘으로 대표 이미지 설정
  - X 버튼으로 삭제
- 최대 10장 제한
- 지원 형식: JPG, PNG, WebP
- 최대 파일 크기: 5MB

## UX 개선사항

1. **뷰 전환 기억**
   - localStorage에 사용자 선호 뷰 저장
   - 다음 방문 시 자동 적용

2. **필터 상태 유지**
   - URL 쿼리 파라미터로 필터/정렬 상태 관리
   - 뒤로가기 시 상태 유지

3. **빠른 편집**
   - 테이블 뷰에서 상태 변경 인라인 편집

4. **일괄 작업** (향후 확장)
   - 여러 객실 선택하여 상태 일괄 변경
   - 복제 기능

5. **숙소별 그룹화 옵션**
   - 카드 뷰에서 숙소별로 그룹화 표시 옵션

## 반응형 디자인

- **모바일**: 카드 1열, 테이블은 카드로 자동 전환
- **태블릿**: 카드 2열, 테이블 스크롤
- **데스크톱**: 카드 3열, 테이블 전체 표시
- Wizard는 중앙 정렬, 최대 너비 800px

## 향후 확장

1. **가격 정보 연동**
   - 요금제 관리와 연결
   - 객실별 시즌 요금 설정

2. **재고 관리**
   - 날짜별 객실 재고 현황
   - 예약 가능 상태 표시

3. **통계**
   - 객실별 예약률
   - 인기 객실 순위

4. **배치도**
   - 층별 객실 배치도 시각화
   - 드래그앤드롭으로 위치 설정
